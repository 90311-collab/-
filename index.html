Python 原始邏輯與演算法對照表

這款網頁遊戲的底層核心邏輯，完全來自以下這段精簡的 Python 程式碼！

🐍 rps_game.py Python 3.x 

# 1. 冒險者登入與裝備
name = input("請輸入你的冒險者名字：")
equipment = input("請選擇你的使用裝備：")
print(f"歡迎【{name}】！裝備【{equipment}】！")

import random  # 隨機魔法模組

player_wins = 0
computer_wins = 0
round_num = 1
options = ["剪刀", "石頭", "布"]

# 2. BO5 搶三勝迴圈條件 (勝場皆小於 3)
while player_wins < 3 and computer_wins < 3:
    print(f"--- 第 {round_num} 回合 ---")
    player_choice = input("請出拳 (剪刀、石頭 或 布)：")

    # 4. 電腦隨機出拳
    computer_choice = random.choice(options)

    # 5. 勝負判斷邏輯
    if player_choice == computer_choice:
        print("平手！沒有人得分。")
    elif (player_choice == "剪刀" and computer_choice == "布") or \
         (player_choice == "石頭" and computer_choice == "剪刀") or \
         (player_choice == "布" and computer_choice == "石頭"):
        print("🎉 這回合你贏了！")
        player_wins = player_wins + 1
    else:
        print("💥 這回合電腦贏了！")
        computer_wins = computer_wins + 1

    round_num = round_num + 1

# 6. 最終結算
if player_wins == 3:
    print(f"🏆 恭喜你以 {player_wins} : {computer_wins} 獲勝！")

💡 國中生程式學習重點筆記

📌 `while` 迴圈條目 player_wins < 3 and computer_wins < 3 表示只要雙方都還沒達到 3 勝，遊戲就會繼續循環。
🎲 `random.choice()` 隨機模組 讓電腦從列表 ["剪刀", "石頭", "布"] 中隨機抽一個選項，模擬真實對決的不可預測性。
⚖️ `if-elif-else` 邏輯判斷 利用 == 判斷平手，並用 or 組合玩家贏的三種組合，簡單清晰！
